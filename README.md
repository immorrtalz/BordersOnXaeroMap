This is a simple [open source](https://github.com/immorrtalz/BordersOnXaeroMap) addon for the [Xaero's World Map](https://modrinth.com/mod/xaeros-world-map), which adds visual chunk-based zones (borders) everyone could view on the map.

> ### IMPORTANT
> The mod is currently in **alpha**, and at the moment it only works locally. It is <ins>expected to have a LOT of fundamental changes</ins> internally.\
> Don't expect support for other Minecraft versions and mod loaders until it is somewhat finished for `1.21.1 NeoForge`.

## ✨ Features
- Obviously, integration with the [Xaero's World Map](https://modrinth.com/mod/xaeros-world-map)
- Toggle all zones (local only) *(not being saved on the map closure currently)*
- Click on a zone to make it active. Click on any empty spot to clear active zone
- Draw mode (draw a new zone if no active zone is selected or add/erase to/from currently active one). Hold `LMB` to add, `Shift + LMB` to erase
- Edit zone (rename, change border and fill appearance with a palette of 14 predefined colors). The menu could be accessed by the toolbar button and by double-clicking on a zone
- Delete zone
- *[Planned]* Multiplayer support *(local only currently)*
- *[Planned]* Private and public zones *(the exact concept is WIP)*

> ### A note from the author
> I'm not an expert in mod making and I don't really know Java, but I have some experience with game development on Unity (C#, which is somewhat similar), web development (JS/TS) and graphic design (Figma).\
