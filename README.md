A simple addon for the [Xaero's World Map](https://modrinth.com/mod/xaeros-world-map), which adds vector and chunk-based zones with borders everyone could see on the map.

> ### IMPORTANT
> The mod is currently in **alpha**, and at the moment it only works locally. It is <ins>expected to have a LOT of fundamental changes</ins> internally.\
> Don't expect support for other Minecraft versions and mod loaders until it is somewhat finished for `1.21.1 NeoForge`.

<br>

<img src="https://cdn.modrinth.com/data/CFTMguCN/images/48d39e0cf31a2372caeab52cc486a8f3d83aca11.png" alt="World map view"/>

## ✨ Features
- Integration with the [Xaero's World Map](https://modrinth.com/mod/xaeros-world-map)
- Toggle all zones visibility (local only) *(not being saved on the map closure currently)*
- Click on a zone to operate on it. Click on any empty spot to clear selection
- Draw mode (draw a new zone if no zone is selected or add to or erase from selected one). Hold `LMB` to add, `Shift + LMB` to erase *(will try to make it RMB for erasing)*
- Edit zone info (rename, change border and fill colors). The menu could be accessed by the toolbar button and by double-clicking on a zone
- Delete zone
- *[Planned]* Multiplayer support *(local only currently)*
- *[Planned]* Private and public zones *(the exact concept is WIP)*

## 🔗 Dependencies
- [Xaero's World Map](https://modrinth.com/mod/xaeros-world-map) (client-only)
